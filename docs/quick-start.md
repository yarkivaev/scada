# Quick-start guide

Start a SCADA plant API with one machine and one sample reading. You will use the same topology and state routes that a site serves to its clients.

## Install SCADA

With Node.js 22 or later, run this command in a new directory.

```sh
npm install @yarkivaev/scada
```

## Start a local plant

Save this example as `plant.mjs`.

```js
/** Loopback-only plant with a simulated temperature reading. */
import { createServer } from 'node:http';
import { acknowledgedAlert, alert, alerts, initialized, machine, plant, plantApi, shop } from '@yarkivaev/scada';

const history = alerts(alert, acknowledgedAlert);
const temperature = {
    name() {
        return 'Temperature';
    },
    current() {
        return { found: true, value: 42, timestamp: new Date(), unit: '°C' };
    }
};
const mixer = machine('mixer', { sensors: { temperature }, alerts: history });
const workshop = shop('workshop', initialized({ mixer }, Object.values), history);
const demo = plant(initialized({ workshop }, Object.values));
const api = plantApi('/api/v1', demo);
const server = createServer((request, response) => {
    return api.handle(request, response);
});
server.listen(Number(process.env.PORT ?? 3000), '127.0.0.1', () => {
    process.stdout.write(`http://127.0.0.1:${server.address().port}\n`);
});
```

```sh
node plant.mjs
```

The example prints its loopback address. Set `PORT` to a free port if 3000 is in use.

## Read equipment and state

From another terminal, list the machines and read the mixer's current state.

```sh
curl --fail http://127.0.0.1:3000/api/v1/machines
curl --fail http://127.0.0.1:3000/api/v1/machines/mixer/state
```

The first request returns the machine you configured.

```json
{"items":[{"id":"mixer","name":"mixer"}]}
```

The second returns an item with key `temperature`, value `42`, unit `°C`, and the timestamp generated by the sensor. Open [the topology endpoint](http://127.0.0.1:3000/api/v1/topology) to see the workshop, mixer and sensor in one graph.

## Choose a deployment

- To run your own plant entrypoint, see [Run the site API](reference/cli.md#run-the-site-api).
- To connect persistent measurements, follow [Connect ClickHouse sensors](reference/javascript-api.md#connect-clickhouse-sensors).
- To run a site with storage and broker services, follow [Helm installation](install/helm.md).
- To collect device readings and classify them into timeline segments, see [Collector runtime](collect/runtime.md) and [Supervisor engine](../supervisor-engine/README.md).

Use Ctrl+C to stop the local API.
